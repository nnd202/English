# English

Appli personnelle pour travailler la prononciation de l'anglais américain : cartes à retourner (IPA du Cambridge Dictionary, flaps et liaisons, voix du téléphone), jouées en **Sprint** contre la montre, avec répétition espacée FSRS.

En ligne : https://nnd202.github.io/English/

- Vérification : `node tools/check.mjs`
- Contenu : `data/lots/` (un fichier par lot)
